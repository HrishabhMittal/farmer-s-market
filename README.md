# Farmer's Market
[![Play on itch.io](https://img.shields.io/badge/Play_on-itch.io-FA5C5C?style=for-the-badge&logo=itch.io)](https://plasma-gamer29.itch.io/farmers-market)

This repository contains the fully compilable source code for **[Farmer's Market](https://plasma-gamer29.itch.io/farmers-market)**, created as an official submission for the **Brackey's Game Jam 2026.2**.

## Play the Game
You can play the compiled, ready-to-run version of the game in your browser or download it here:
